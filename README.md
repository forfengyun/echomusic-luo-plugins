# echomusic-luo-plugins

EchoMusic（酷狗概念版）第三方插件集合，全部为 **Luo 原创自研**，仅供 EchoMusic 插件系统使用。

## 插件清单

| 插件 | 功能 |
|---|---|
| echomusic-kgm-convert | 酷狗加密音频还原（.kgm/.kgg → MP3/FLAC/OGG/WAV） |
| echomusic-resume | 断点续播 |
| kugou-concept-sign | 酷狗概念版每日签到 / 概念币 |
| echomusic-timer | 定时停止播放 / 定时关机 |
| echomusic-payskip | 遇付费歌曲自动跳过 |
| echomusic-vinyl-rotation | 黑胶旋转唱片 UI |
| echomusic-sdk | 插件公共依赖库 |

## 安装

1. 完全退出 EchoMusic；
2. 将对应插件文件夹复制到 `%APPDATA%\echo-music\plugins\` 下；
3. 重新打开 EchoMusic，在插件管理页启用。
